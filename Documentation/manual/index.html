Welcome to MQMyChat

Last Updated: 2026-06-11

MQMyChat is a chat routing plugin for MacroQuest that organizes your EverQuest chat into customizable channels. Instead of watching a single scrolling chat window, you get separate tabs for combat, tells, guild chat, loot, and anything else you want to track.

What It Does

  • Sorts your chat — Incoming messages are automatically routed to the right channel based on pattern matching
  • Color-codes messages — Apply custom colors to different types of messages within each channel
  • Hides unwanted spam — Filter out messages you don't want to see
  • Saves configurations — Create presets you can share across characters or switch between
  • Pops out channels — Open any channel in its own floating window
  • Sends commands — Type directly into any channel to send chat (say, group, guild, etc.)

Quick Start

  1. Load the plugin: type /plugin MQMyChat in your EQ chat
  2. Open the window: type /mychat show
  3. You'll see a tabbed window with pre-configured channels like Combat, Tells, Guild, and more
  4. Click any tab to see messages for that channel
  5. Type in the input box at the bottom and press Enter to send a message
MQMyChat comes with 14 pre-configured channels out of the box. You can customize them, add new ones, or remove ones you don't need.
