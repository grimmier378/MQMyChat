Channels & Events

Last Updated: 2026-06-11

Channels are the heart of MQMyChat. Each channel watches for specific patterns in your chat and collects matching messages. You control what each channel catches using events and filters.

How It Works

Incoming Chat Message │ ▼ Does it match any event pattern? │ Yes ▼ No ──▶ Goes to Spam channel (if enabled) Route to channel │ ▼ Do any filters match? │ Yes ▼ No ──▶ Use default event color Apply filter color (or hide if filter is set to hidden)

Understanding Events

An event is a pattern that tells MQMyChat what text to watch for. When an incoming message matches the pattern, it gets routed to that event's channel.

Event Pattern Syntax

Patterns use a simple wildcard system:

PatternMeaningExample Match
#*#heals#*#Any text containing "heals""Soandso heals you for 500 points"
#*#tells you,#*#Any text containing "tells you,""Soandso tells you, 'Hello!'"
#*#slashes#*#Any text containing "slashes""You slash a gnoll for 200 damage"

The #*# means "any text here". So #*#heals#*# matches any message with "heals" anywhere in it.

Understanding Filters

A filter refines what happens after an event matches. Filters let you:

  • Color-code specific messages within a channel
  • Hide messages you don't want to see
  • Highlight messages from specific people (your group, your pet, etc.)

How Filters Work

  • Filter 0 (Default) — Sets the base color for all messages in this event. No pattern matching needed.
  • Filter 1, 2, 3... — Conditional filters checked in order. The first one that matches wins.
  • If a conditional filter matches and is marked Hidden, the message is discarded entirely.
  • If a conditional filter matches and is not hidden, its color overrides the default.
Important: Filters are case-sensitive patterns — match the exact case as it appears in the game. The pattern you say matches only that exact lower-case text, not You say. Use ^ at the start of a filter to anchor the match to the beginning of the line (e.g., ^You matches only lines that start with "You").

Filter Tokens

Filters support special tokens that are replaced with actual game values at match time. This lets you create dynamic filters like "highlight messages about my pet" without hardcoding names.

TokenReplaced WithExample Use
M3Your character nameHighlight your own damage in a different color
PT1Your pet's nameTrack your pet's combat messages
PT3A group member's pet nameTrack group pets
M1Main Assist's nameHighlight MA's target calls
TK1Main Tank's nameHighlight tank's combat messages
G1 - G5Group member in slot 1-5Filter by specific group member
GP1Any group memberHighlight all group combat
H1Group healer (Druid, Cleric, Shaman)Highlight healer messages
RLRaid Leader's nameHighlight raid leader commands
P3Player name from chat lineMatch the person speaking
N3NPC name from chat lineMatch the NPC in the message
NO2Invert the match (use in front of other tokens)NO2M3 = messages NOT from your character

Special Characters in Filters

If your filter contains punctuation or special characters and behaves unexpectedly, you may need to escape them. Use a percent sign % followed by the special character. Here are the most common ones:

What You Want to MatchWrite It AsExample
A literal percent sign%%50%% matches "50%"
Parentheses%( or %)%(Warrior%) matches "(Warrior)"
Any digit%ddamage %d+ times matches "damage 5 times"
Any letter%a%a+ heals you matches "Soandso heals you"
Any space%sMatches whitespace characters

In most cases, plain words work fine without any special handling. Only use these escapes if a filter isn't matching the way you expect.

The Settings Window

Channels are created and edited in the Settings window. Open it with the gear button in the menu bar (or type /mychat config). On the left is a list of every channel plus Main; selecting one shows its Settings tab and Events and Filters tab on the right.

Editing fields: Click a text field (name, echo command, a pattern) to open a small inline popup editor. Type the new value and press Accept to confirm, or Cancel to discard changes. Changes apply immediately to the current session, but are only written to disk when you press Save Settings at the bottom, which also closes the window. Use Close to exit without saving.

Creating a New Channel

  1. Open the Settings window (gear button, or /mychat config)
  2. Click + Add under the channel list
  3. Type the channel name in the popup and press Accept
  4. The new channel is selected automatically — set its Echo on the Settings tab and add events on the Events and Filters tab

Adding Events to a Channel

  1. Select the channel, then open its Events and Filters tab
  2. Click + Add Event at the top of the event list, type a pattern (e.g., #*#guild#*#), and press Accept
  3. Select the event to edit it — click Event Color to set its default color

Adding Filters to an Event

  1. On the Events and Filters tab, select the event you want to add filters to
  2. Below the event's Event Color setting, click Add Filter
  3. Click the new filter's pattern field and enter a pattern or token (e.g., M3 for your name, or GP1 for group members)
  4. Click the colored square next to the pattern to pick a color for matching messages
  5. Check On to enable the filter, Hidden to hide matching messages instead of coloring them, and use up/down arrows to reorder filters
  6. Click the X button to remove a filter
Example: To highlight your own damage in green and hide pet damage in the Combat channel:
• Add a filter with M3 and set it to green
• Add a filter with PT1 and check Hidden

Channel Settings

Each channel has these configurable properties on the Settings tab:

SettingWhat It Does
NameThe display name shown on the channel's tab
EchoThe slash command used when you type in this channel's input (e.g., /say, /gu, /tell)
Font SizeText size for this channel (8-48 pixels)
EnabledWhether the channel's events are active (checked = on)
Main EnableWhether this channel's messages also appear in the Main tab (checked = yes)
Enable LinksMake item links clickable in this channel (checked = enabled)
PopOutOpen this channel in a separate floating window (checked = floating)
LockedLock the pop-out window so it can't be moved or resized (checked = locked)
Remove ChannelDelete this channel entirely (red button at the bottom)

Consider Channel

The Consider channel has special behavior: messages are automatically color-coded by mob difficulty level, matching the standard EverQuest consider colors (grey, green, light blue, blue, white, yellow, red). You don't need to set up filters for this — it happens automatically.

Spam Channel

The Spam channel (disabled by default) catches any message that isn't matched by any other channel. Enable it from the Options menu if you want to see "unclaimed" messages. This is useful for debugging your event patterns — if something shows up in Spam, you know you need to add an event for it.
