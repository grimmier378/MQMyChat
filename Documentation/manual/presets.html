Presets

Last Updated: 2026-06-11

Presets let you save and switch between different channel configurations. This is useful if you want different chat setups for grouping vs. raiding vs. solo play, or if you want to share a configuration across characters.

How Presets Work

  • A preset is a saved collection of channels, events, and filters
  • Presets are stored per server — all characters on the same server share the same preset library
  • Each character has one active preset at a time
  • Characters can have per-character overrides on top of the active preset (e.g., different channels enabled, different tab order)
  • A "Default" preset is created automatically for each new character
Saving is crash-safe: if a save is interrupted, the preset is left exactly as it was rather than half-written, so your channels and filters can't be corrupted mid-save.

Switching Presets

From the Menu Bar

  1. Click the Presets menu in the menu bar
  2. Select a preset from the dropdown
  3. Your settings are saved, the new preset loads, and channels update immediately

From the Command Line

/mychat preset MyRaidSetup

Switches to the preset named "MyRaidSetup".

Managing Presets

Open the Preset Manager by clicking Manage Presets... in the Presets menu. The manager has collapsible sections for each operation below.

Copy Current Preset

Creates an exact copy of your current settings with a new name. This is the easiest way to create a variant — copy first, then modify.

  1. In the Copy Current Preset section, type a name for the copy in the text field
  2. Click Copy
  3. Switch to the new preset and make your changes in the Settings window

Create New Blank Preset

Creates an empty preset with no channels. Useful if you want to build a configuration from scratch.

  1. In the Create New Blank Preset section, type a name in the text field
  2. Click Create
  3. Switch to it from the Presets dropdown and add channels manually in the Settings window

Rename Preset

  1. In the Rename Preset section, click the dropdown and select the preset to rename
  2. Type the new name in the text field
  3. Click Rename

Delete Preset

  1. In the Delete Preset section, click the dropdown and select a preset to delete (you cannot delete the active preset)
  2. Click Delete
  3. Confirm the deletion when prompted
Deleting a preset removes all its channels, events, and filters permanently. This cannot be undone.

Per-Character Overrides

When multiple characters share the same preset, each character can still customize:

  • Which channels are enabled/disabled
  • Tab order
  • Pop-out settings
  • Font sizes per channel
  • Echo commands per channel
  • Link settings per channel

These overrides are saved separately from the preset itself, so one character's changes don't affect others using the same preset.

Suggested Preset Setups

Solo/Leveling: Keep Combat, Loot, Exp, and Consider. Disable Guild and Raid. Enable Spam to catch anything you miss.
Raiding: Enable Raid, Guild, Combat, Crits. Pop out Tells so you don't miss whispers during busy fights. Increase font size for Combat.
Tradeskill/Crafting: Disable Combat, Crits. Keep Tells, Guild, OOC. Create a custom "Tradeskill" channel watching for craft-related messages.
