Main Window

Last Updated: 2026-06-11

The main MQMyChat window is your central hub for organized chat. It has a menu bar at the top, tabs for each channel, and an input box at the bottom.

The settings and preset screens use smooth, animated controls (sliding tabs, animated checkboxes and drop-downs, and expanding sections) that follow your chosen theme's colors. This is purely visual — everything works exactly as described below.

Menu Bar

Lock Button

Toggles whether the window can be moved and resized. When locked, the window stays in place and the title bar is hidden. Use /mychat lock and /mychat unlock as shortcuts.

Settings Button (gear)

Opens the Settings window — a two-pane editor with a channel list (including Main) on the left and Settings / Events and Filters tabs on the right, where you manage all your channels, events, and filters.

Options Menu

See Settings & Options for a full description of every option.

Channels Menu

Quick checkboxes to enable or disable each channel. When you disable a channel, its events stop matching and no new messages are routed to it. The channel and its settings are preserved — just toggle it back on when you want it.

Disabling a channel here is the fastest way to temporarily stop seeing certain types of messages without deleting anything.

Links Menu

Per-channel checkboxes to enable clickable item links. When enabled, item links in that channel's messages become clickable (like in the EQ chat window).

PopOut Menu

Per-channel checkboxes to open channels in their own floating windows. See Pop-Out Windows below.

Presets Menu

A dropdown to switch between saved presets, plus a "Manage Presets..." button to open the Preset Manager for advanced operations like copying, renaming, and deleting.

Tab Bar

Each enabled channel gets its own tab. The Main tab is always first and shows a combined view of messages from all channels that have "main enable" turned on.

Reordering Tabs

Drag any tab left or right to reorder. The new order saves automatically after about 3 seconds.

Right-Click Menu

Right-click (or use the popup button on) any channel tab to see:

  • Edit — Opens the channel editor for events and filters
  • Pop Out — Opens this channel in a separate floating window
  • Delete — Removes the channel entirely

Console Area

The scrollable text area showing messages for the selected channel. Messages appear with:

  • Timestamps in yellow (if enabled): [HH:MM:SS]
  • Custom colors based on your filter settings
  • Clickable links if the Links option is enabled for that channel

The console auto-scrolls to the newest message (if auto-scroll is enabled). Scroll up to read history.

Input Box

At the bottom of each tab is an input box. Type a message and press Enter to send it.

How Messages Are Sent

  • If your message starts with /, it's sent as-is (e.g., /gu Hello guild!)
  • If your message doesn't start with /, the channel's echo command is prepended. For example, if the echo command is /say and you type Hello, it sends /say Hello
  • The Main tab uses its own echo command (default: /say), configured in the Settings window under the Main channel's Settings tab

Command History

Press Up and Down to scroll through your previous commands. Each channel keeps its own history (up to 100 entries per channel).

Local Echo

When enabled (default), your typed messages appear in gray in the console immediately, so you can see what you sent. Toggle this in Options.

Pop-Out Windows

Any channel can be "popped out" into its own separate floating window. This is useful for channels you always want visible, like Tells or Guild chat.

How to Pop Out a Channel

  • Use the PopOut menu in the menu bar, or
  • Right-click a tab and select Pop Out

Pop-Out Window Features

  • Titled "My Chat - " and floats independently of the main window
  • Has its own Lock button and Settings button at the top
  • Can be positioned anywhere on screen and resized (unless locked)
  • Has its own console and input box, just like a tab in the main window
  • When a channel is popped out, it no longer appears as a tab in the main window (just the floating window shows it)

Focus Key

If you enable the focus key in Options, pressing a specific key (like RightShift or `) will immediately put your cursor in the input box of the currently visible channel. This lets you start typing without clicking.
