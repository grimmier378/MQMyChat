Getting Started

Last Updated: 2026-06-11

Loading the Plugin

  1. Make sure MQMyChat.dll is in your MacroQuest plugins folder
  2. In EverQuest, type: /plugin MQMyChat
  3. The plugin loads and creates its database automatically
  4. Type /mychat show to open the chat window
To auto-load MQMyChat every time you start MacroQuest, add MQMyChat to your plugin list in the MacroQuest configuration.

First Run

When you log in for the first time, MQMyChat automatically:

  • Creates a "Default" preset for your character
  • Populates 14 pre-configured channels
  • Starts routing chat to the appropriate channels

You don't need to configure anything to get started — just open the window and your chat will already be sorted.

Default Channels

These channels come pre-configured for every new character:

ChannelWhat It Shows
NPCNPC dialog — quest text, vendor messages, and NPC speech
ConsiderCon messages when you consider a mob — color-coded by difficulty (grey, green, blue, yellow, red, etc.)
CombatMelee and spell damage, healing, misses, and combat-related messages
CritsCritical hits, assassinations, finishing blows, crippling blows, and other special combat effects
LootItem drops, looting messages, and corpse notifications
FactionFaction standing changes
OOCOut of character chat and server announcements
ShoutShout channel messages
TellsIncoming and outgoing tells (whispers)
Exp AA ptsExperience and AA point gains
GuildGuild chat messages
RaidRaid chat messages
SayLocal /say messages
SpamEverything not caught by another channel (disabled by default)
The Spam channel is disabled by default. Enable it from the Options menu if you want to see messages that aren't matched by any other channel.

Basic Navigation

  • Click tabs to switch between channels
  • The Main tab shows messages from all channels that have "main enable" turned on
  • Drag tabs to reorder them (order saves automatically after 3 seconds)
  • Right-click a tab to edit, pop out, or delete that channel
  • Type in the input box at the bottom and press Enter to send a message
  • Press Up/Down arrows to scroll through your command history

Per-Character Settings

MQMyChat saves settings separately for each character on each server. When you log into a different character, their settings load automatically. This means:

  • Each character can have different channels enabled/disabled
  • Window position and size are remembered per character
  • Font sizes, themes, and other options are per character
  • Presets are per server — all characters on the same server share the same preset library
