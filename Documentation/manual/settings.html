Settings & Options

Last Updated: 2026-06-11

All configurable options in MQMyChat. Most live in the Options menu of the main window. A few global items (Main Echo, Main Font Size, and Links) are configured in the Settings window under the Main channel entry.

Options Menu Reference

OptionDefaultWhat It Does
Timestamps On Shows a yellow [HH:MM:SS] timestamp before each message. Existing timestamps from EQ are replaced with a standardized format.
Local Echo On Shows your typed messages in gray text in the console immediately when you press Enter, so you can see what you sent.
Auto Scroll On Automatically scrolls the console to the newest message. Turn off if you want to read chat history without being interrupted.
Log Commands Off Logs commands you type to the MacroQuest output window.
Spam Channel Off Enables the Spam channel which catches all messages not matched by any other channel. Useful for debugging your event patterns.
Key Focus Off When enabled, pressing a specific key gives focus to the input box. Configure the key name below this option.
Focus Key Name RightShift Which key activates input focus. This field appears in the Options menu only after you enable Key Focus. Common choices: RightShift, GraveAccent (backtick), Tab.
Max Buffer Lines 5,000 Maximum number of lines kept in memory per console (500-50,000). Higher values use more memory but let you scroll back further.
Theme Default Visual theme for the entire window. See Themes below.
Save Settings — Manually saves all current settings. Settings also auto-save when you log out or close the window.

Main Channel Settings

Click the gear button in the main window to open the Settings window, then select Main in the channel list on the left. Its Settings tab holds these global configuration options:

OptionDefaultWhat It Does
Main Echo /say The slash command prepended to messages typed in the Main tab. Change to /gu for guild, /raid for raids, /tell for tells, etc. Click the field to edit it in a small popup, then press Accept.
Main Font Size 16 Text size in the Main tab (8-48 pixels). Each channel can also have its own independent font size.
Links Off Enables clickable item links globally (checked = enabled). You can also enable/disable links per channel in the Links menu or on each channel's Settings tab.

Changes in the Settings window apply immediately to the current session, but are only written to disk when you press Save Settings (which also closes the window). Use Close to exit without saving.

Where Settings Are Stored

MQMyChat stores settings in two places:

  • Database — Channels, events, filters, presets, and most options are stored in a SQLite database in the MacroQuest resources folder. This database is shared with the Lua version of MyChat for cross-compatibility.
  • INI file — Window visibility (open/closed) is stored in an INI file per character per server.

Settings save automatically when you log out, switch characters, or close the window. Use the "Save Settings" button in Options for a manual save at any time.
