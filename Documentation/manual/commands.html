Commands & TLO

Last Updated: 2026-06-11

Slash commands for controlling MQMyChat and TLO (Top-Level Object) access for macros and Lua scripts.

Slash Commands

All commands use /mychat followed by a subcommand:

CommandWhat It Does
/mychat or /mychat show Opens the main chat window
/mychat hide Closes the main chat window
/mychat send <channel> <message> Sends a message directly to a specific channel's console (doesn't use the channel's echo command — the text appears in the channel but isn't sent to EQ chat)
/mychat clear Clears the main console
/mychat clear <channel> Clears a specific channel's console
/mychat config Opens/closes the Config GUI
/mychat reload Reloads all character settings from the database
/mychat lock Locks the window (prevents moving and resizing)
/mychat unlock Unlocks the window
/mychat preset <name> Switches to the named preset

Examples

/mychat show
/mychat send Combat Testing 1 2 3
/mychat clear Tells
/mychat preset MyRaidSetup
/mychat lock

TLO Access (for Macros)

MQMyChat exposes a ${MyChat} TLO that macros can use to query channel information and send messages.

Reading Information

TLO ExpressionReturnsDescription
${MyChat.Version} Number Plugin version (e.g., 0.1)
${MyChat.ChannelCount} Number How many channels exist
${MyChat.Channel[Combat].Name} Text Channel name (by name lookup)
${MyChat.Channel[2].Name} Text Channel name (by ID lookup)
${MyChat.Channel[Combat].ID} Number Channel ID number
${MyChat.Channel[Combat].Enabled} TRUE/FALSE Whether the channel is active
${MyChat.Channel[Combat].TabOrder} Number Tab position
${MyChat.Channel[Combat].PopOut} TRUE/FALSE Whether the channel has a pop-out window
${MyChat.Channel[Combat].Echo} Text Default slash command (e.g., /say)
${MyChat.Channel[Combat].MainEnable} TRUE/FALSE Whether shown in Main tab

Sending Messages

TLO ExpressionReturnsDescription
${MyChat.Send[Combat,Hello World]} TRUE/FALSE Sends "Hello World" to the Combat channel

The format is ${MyChat.Send[channelName,message]} where the channel name and message are separated by a comma.

Macro Examples

/if (${MyChat.Channel[Combat].Enabled}) {
    /echo Combat channel is active
}

/if (${MyChat.ChannelCount} > 0) {
    /echo MQMyChat has ${MyChat.ChannelCount} channels
}

/echo ${MyChat.Send[Combat,Raid assist on ${Target.CleanName}]}

Lua Access

From Lua scripts, access MQMyChat through the standard MQ TLO interface:

local mq = require('mq')

-- Read channel info
local version = mq.TLO.MyChat.Version()
local count = mq.TLO.MyChat.ChannelCount()
local combatEnabled = mq.TLO.MyChat.Channel("Combat").Enabled()
local combatName = mq.TLO.MyChat.Channel("Combat").Name()

-- Send a message to a channel
mq.TLO.MyChat.Send("Combat,Hello from Lua!")

-- Check if a channel exists and is enabled
if mq.TLO.MyChat.Channel("Tells").Enabled() then
    print("Tells channel is active")
end
The TLO is read-only for channel properties. You can read channel names, IDs, enabled status, etc., but you cannot change settings through the TLO. The only action you can take is Send, which adds text to a channel's console.
