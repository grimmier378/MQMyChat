Building MQMyChat

Last Updated: 2026-06-11

Build Configuration

MQMyChat is built as a Win32 (x86) Release DLL using Visual Studio 2022+ and CMake integration. EverQuest is a 32-bit application, so the plugin must be compiled for the Win32 platform.

Build Environment

On this development machine, Visual Studio 2022 Insiders is available at:

C:\Program Files\Microsoft Visual Studio\18\Insiders\MSBuild\Current\Bin\MSBuild.exe

MSBuild Command

Build MQMyChat with the following command:

C:\Program Files\Microsoft Visual Studio\18\Insiders\MSBuild\Current\Bin\MSBuild.exe "D:\gitStuff\macroquest\plugins\MQMyChat\MQMyChat.vcxproj" -p:Configuration=Release -p:Platform=Win32 -nologo -verbosity:minimal
VS2022 Community Path: If building on a machine with the older Community edition at C:\Program Files\Microsoft Visual Studio\2022\Community\, adjust the MSBuild path accordingly. The Insiders path shown above is the standard for this development environment.

Project Structure

The MQMyChat.vcxproj file is managed by CMakeLists.txt and defines the following build targets:

Source Files

File Purpose
MQMyChat.cpp Plugin entry point, engine lifecycle, chat routing, Blech events, token substitution
MyChatDatabase.cpp SQLite schema initialization, presets, global settings, character overrides
MyChatRenderer.cpp ImGui windows, tabs, popouts, configuration UI
MyChatTLO.cpp TLO registration and member resolution for ${MyChat}
Core/Widgets.cpp Shared styled/animated widget implementations (synced from MQMyUI)

Header Files

File Purpose
MQMyChat.h Engine class definition, plugin globals
MyChatChannel.h Data structures: ChatFilter, ChatEvent, ChatChannel, MyChatSettings, PresetInfo
MyChatDatabase.h Database interface: Open, Close, schema, presets, load/save
MyChatRenderer.h ImGui renderer interface and window management
MyChatTLO.h TLO member type definitions
MyChatAPI.h Exported pure-virtual interface for other plugins
Theme.h 11 ImGui color themes (shared with MQMyDPS)
Core/Widgets.h Styled widget declarations (synced from MQMyUI)

Dependencies

MQMyChat links against the following libraries and frameworks:

MacroQuest Core

  • MQ2Main — Core MacroQuest engine and hooks
  • eqlib — EverQuest data structures and game state
  • pluginapi — Plugin interface and registration

Third-Party Libraries

  • sqlite3 — SQLite database engine (vcpkg: unofficial-sqlite3)
  • lua51 — LuaJIT interpreter for pattern matching and token substitution
  • fmt — String formatting library

ImGui & Rendering

  • ConsoleWidget (Zep) — Text console with syntax highlighting and command history
  • ImGui — Immediate-mode GUI rendering
  • im_anim — Animation and transition helpers for ImGui
  • AlphaMask — Alpha-masked texture rendering for styled bars
  • IconsFontAwesome — Font Awesome icon glyphs in ImGui

Output & Installation

After a successful build, the compiled DLL is placed at:

D:\gitStuff\macroquest\plugins\MQMyChat\build\Emu\bin\release\plugins\MQMyChat.dll

To load the plugin in EverQuest, use the command:

/plugin MQMyChat
Plugin Loading: Ensure that MQMyChat.dll is copied to the correct EverQuest plugin directory (typically C:\Program Files\Sony Online Entertainment\Everquest\plugins\) and load it after other dependencies like MQ2Main are initialized.

Shared Components

Core/Widgets.{h,cpp} are kept verbatim in sync with MQMyUI to ensure consistency across the MQMy* plugin ecosystem. When updating these files, make sure to propagate changes to the MQMyUI copy and vice versa. See the Renderer documentation for details on the myui styled widget set.

CMakeLists Configuration

The build is configured via CMakeLists.txt with the following setup:

  • Shared library target: MQMyChat
  • Folder: Plugins in Visual Studio solution explorer
  • Link library: unofficial::sqlite3::sqlite3 (vcpkg dependency)
  • Plug-in properties: Applied via target_Plugin_props() macro from the MacroQuest build system
