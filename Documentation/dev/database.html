Database

Last Updated: 2026-06-11

SQLite persistence layer: schema, load/save flows, presets, per-character overrides, and transactional writes with RAII rollback.

Connection

PropertyValue
Path%PathResources%\MyChat.db
ModeWAL (Write-Ahead Logging) for concurrent read/write

The schema is designed to match the Lua MyChat plugin's database for cross-compatibility between C++ and Lua versions.

Schema Notes

  • presets: Template preset uses id=-1. UNIQUE constraint on (preset_name, server).
  • channels: User-facing channel ID (0, 1, 2...) distinct from row ID. Linked to preset.
  • events: Blech patterns (e.g., "#*#heals#*#") matched against chat lines.
  • filters: Color + visibility rules per event. filter_index 0 = default, 1+ = conditional.
  • filters colors: Stored as float 0.0-1.0, converted to uint8 0-255 on load/save via ImColor.
  • global_settings: 13 keys per (char_name, server): locked, timeStamps, Scale, themeIdx, doLinks, mainEcho, MainFontSize, LogCommands, keyFocus, keyName, localEcho, autoScroll, maxBufferLines.
  • char_channel_overrides: Per-character channel property overrides (enabled, echo, main_enable, enable_links, pop_out, locked, scale, main_font_size, tab_order).

Transaction Safety

RAII TransactionGuard (MyChatDatabase.h:41): All four transactional writes—SaveSettings, SaveGlobalSettings, SaveCharChannelOverrides, and SeedDefaultChannels—use a private RAII pattern:
  • TransactionGuard(this) issues BEGIN TRANSACTION on construction.
  • Destructor issues ROLLBACK unless commit() was called.
  • Each function tracks a local bool ok, set false on any PrepareAndStep, sqlite3_step, or ExecSQL failure.
  • ExecSQL (MyChatDatabase.cpp:42) returns bool to surface failures.
  • Only calls tx.commit() when ok is still true.
Result: A failed delete-and-reinsert rolls back entirely instead of leaving a half-rebuilt preset or corrupted overrides.

Preset Switch Flow (UI-triggered)

  1. SaveCharacterSettings() — persist current preset's channels and overrides
  2. database->SetActivePreset(server, charName, newPresetId) — update char_active_preset
  3. UnloadCharacterSettings() — clear in-memory settings
  4. LoadCharacterSettings() — load new preset

Schema Versioning & Migrations

  • Version storage: Single row in schema_version table (id=1).
  • RunMigrations() (MyChatDatabase.cpp:99): Applies incremental migrations per version.
  • GetSchemaVersion() / SetSchemaVersion(): Query/update version number.
  • Current version: 1 (includes char_channel_overrides table and all indexes).

Per-Character Overrides

The char_channel_overrides table allows each character to override channel properties without modifying the shared preset:

  • When to use: Player customizes a channel within an active preset (e.g., disables a channel, changes font size, adjusts echo command).
  • Load order: Base channel properties come from channels table, then LoadCharChannelOverrides applies matching overrides.
  • Save: SaveCharChannelOverrides (transactional) deletes all current overrides and re-inserts the full set.
  • Cascade: FK to presets ensures overrides are deleted if a preset is deleted.
