Chat Routing

Last Updated: 2026-06-11

The core pipeline: from incoming EQ chat through Blech pattern matching, filter evaluation, token substitution, and Lua pattern matching to colored console output.

End-to-End Flow

EQ Chat Message │ ▼ OnIncomingChat (MQMyChat.cpp:189) / OnWriteChatColor (MQMyChat.cpp:196) │ ▼ ProcessIncomingChat (MQMyChat.cpp:598) / ProcessWriteChat (MQMyChat.cpp:622) │ ▼ m_blech→Feed(line) ── Blech B-Tree pattern evaluation │ ▼ (on match) BlechCallback (MQMyChat.cpp:578) ── looks up channelId/eventIndex via m_blechEventMap │ ▼ RouteToChannel (MQMyChat.cpp:633) │ ├── Filter evaluation loop (lines 664+) │ ├── MatchFilter (MQMyChat.cpp:1244) │ │ ├── SubstituteTokens (MQMyChat.cpp:1042) │ │ └── PatternFind (MQMyChat.cpp:904) │ ├── Hidden filter? → discard line │ └── Color filter? → apply color │ ├── Claim line (m_claimedLines, 500ms TTL) ├── Consider color mapping │ ▼ AppendToConsole (MQMyChat.cpp:842) ├── Strip/reformat timestamps ├── Append to channel console └── Optionally append to main console (if mainEnable) Unclaimed lines → Spam channel (if enabled, in ProcessIncomingChat)

Blech Event Registration

RegisterBlechEvents() (MQMyChat.cpp:536-562) sets up the pattern matching engine:

  1. Iterates all channels in settings.channels
  2. For each enabled channel, iterates its enabled events
  3. Calls m_blech→AddEvent(eventString, BlechCallback, &data)
  4. Stores returned ID in m_blechEventMap[id] = {channelId, eventIndex}
  5. Also stores ID in event.blechId for later removal
Blech uses # as wildcard delimiter and | as separator. Example patterns: "#*#heals#*#", "#*#tells you,#*#", "#*#slashes#*#"

Filter Evaluation

RouteToChannel(channelId, eventIndex, line, color) (MQMyChat.cpp:633):

  1. Find channel in settings.channels by channelId
  2. Find matching event by eventIndex
  3. Iterate filters in order:
    • filterIndex 0: Default color (no pattern matching, always applies)
    • filterIndex 1+: Conditional — calls MatchFilter(line, filter)
    • If match + hidden=true: line discarded entirely
    • If match + hidden=false: use filter's color, stop checking
  4. If non-default filters exist but none matched: skip line
  5. Claim line in m_claimedLines with 500ms TTL
  6. Special consider channel: map CONCOLOR_* to MQColor
  7. AppendToConsole() to channel console + optionally main console

Token Substitution

SubstituteTokens(pattern, chatLine) (MQMyChat.cpp:1042) replaces symbolic tokens in filter patterns with actual game values at match time. Tokens are matched at word boundaries and all occurrences of the matched token type are replaced via ReplaceTokenWB / ContainsTokenWB (MQMyChat.cpp:1022, 1010). Only one token type is substituted per pattern (the first matching branch returns), matching the Lua client's elseif chain.

Pattern Find

PatternFind(line, pattern) (MQMyChat.cpp:904):

  1. Empty pattern matches everything (returns true).
  2. All filters are matched as Lua patterns: Calls lua_pcall on string.find(line, pattern) using m_luaState. Matching is case-sensitive, and Lua pattern syntax (^, $, %d, %a, character classes, etc.) is honored directly.
  3. Degraded fallback — only when m_luaState is null (LuaJIT failed to initialize): a literal case-sensitive text.find(pattern) substring match.
No heuristic detection: There is no %-detection heuristic and no separate plain-substring code path. The previous IsLuaPattern helper was removed. All patterns use Lua string.find, making matching always case-sensitive and supporting full Lua regex syntax natively. The ^ anchor is handled natively by Lua as a start-of-line anchor — it is not special-cased in code.

Match Filter

MatchFilter(line, filter) (MQMyChat.cpp:1244):

  1. matchStr = SubstituteTokens(filter.filterString, line)
  2. found = PatternFind(line, matchStr)
  3. If NO2 prefix was present: return !found

Name Extraction

ExtractNameFromLine(line) (MQMyChat.cpp:932–975) searches for actor names in chat by finding keywords:

Keywords: "pet tells you", "tells you,", "says to you,", "says,'", "whispers,", "shouts,", "slashes", "pierces", "kicks", "crushes", "bashes", "hits", "tries", "backstabs", "bites", "begins"

Extracts the name preceding the keyword. Used by P3/N3 token substitution.

IsNPCName(name) (MQMyChat.cpp:914) validates whether a name is an NPC via GetSpawnByName.

Spam Channel

Channel ID 9000 (CHANNEL_SPAM). Lines not claimed by any channel during Blech processing are routed to the spam channel if enabled. Checked in ProcessIncomingChat after m_blech→Feed() completes.

Claimed lines are tracked in m_claimedLines with a 500 ms TTL (via CLAIMED_TTL). This deduplicates claimed lines within the time window.

Console Output

AppendToConsole(console, line, color, ...) (MQMyChat.cpp:842):

  1. Strips existing timestamps like [HH:MM:SS] from line
  2. If timestamps enabled: generates new yellow [HH:MM:SS] prefix
  3. Calls console→AppendText() with separately colored segments
