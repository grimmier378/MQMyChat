TLO

Last Updated: 2026-06-11

The ${MyChat} Top-Level Object provides macro and Lua script access to MQMyChat channel metadata and the Send method. The TLO is purely read-only for member access; only the Send method modifies state (appends text to a channel console).

${MyChat} Methods

MethodSyntaxReturnDescription
Send ${MyChat.Send[channelName,message]} bool Sends message to the named channel. Parses index as "channelName,message", splits on first comma, calls g_chatEngine->SendToChannel(). Returns TRUE on success.

Send Implementation: MyChatType::GetMember() (MyChatTLO.cpp:106-127) detects the Send method, extracts the index string, splits on the first comma to separate channel name and message, then routes through the engine.

${MyChat.Channel[...]} Members

Access a channel by name or ID: ${MyChat.Channel[Combat]} or ${MyChat.Channel[2]}. The lookup is defined in MyChatChannelType::GetMember() (MyChatTLO.cpp:7-89).

MemberTypeDescription
.NamestringChannel display name
.IDintChannel ID number (1-based)
.EnabledboolWhether the channel is active/visible
.TabOrderintTab position in the main window (rendering order)
.PopOutboolWhether the channel has a separate pop-out window
.EchostringDefault slash command (e.g., /say, /tell)

ToString() on a MyChatChannelType instance returns the channel name.

Usage Examples

Macro:

/echo ${MyChat.Version}                  --> 0.1
/echo ${MyChat.ChannelCount}             --> 5
/echo ${MyChat.Channel[Combat].Name}     --> Combat
/echo ${MyChat.Channel[Combat].Enabled}  --> TRUE
/echo ${MyChat.Channel[2].ID}            --> 2
/echo ${MyChat.Channel[Combat].Echo}     --> /say
/echo ${MyChat.Send[Combat,Hello World]} --> TRUE

Lua:

local version = mq.TLO.MyChat.Version()
local count = mq.TLO.MyChat.ChannelCount()
local name = mq.TLO.MyChat.Channel("Combat").Name()
local enabled = mq.TLO.MyChat.Channel("Combat").Enabled()
mq.TLO.MyChat.Send("Combat,Hello from Lua")

Data Flow

All member access is read-only. The TLO reflects current engine state but cannot modify channel settings. Only the Send method modifies state.

Macro/Lua │ ├── ${MyChat.Channel[X].Property} (read-only) │ └── MyChatChannelType::GetMember() │ └── Iterate g_chatEngine->settings.channels │ └── Read ChatChannel struct field │ └── Return to caller │ └── ${MyChat.Send[channel,msg]} (write) └── MyChatType::GetMember() (detects Send method) └── Parse "channel,msg" and call └── g_chatEngine->SendToChannel(name, msg) └── Find/create channel, AppendToConsole()
