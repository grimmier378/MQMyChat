MQMyChat Developer Documentation

Last Updated: 2026-06-11

MQMyChat is a native C++ MacroQuest plugin that provides an advanced chat router with Blech pattern matching, SQLite presets, Zep consoles, and a ${MyChat} TLO. It maintains cross-compatibility with the original Lua MyChat client through a shared SQLite schema, while adding Lua-JIT-backed filter patterns, an exported C++ ChatAPI for inter-plugin communication, and ImGui-based configuration and visualization.
