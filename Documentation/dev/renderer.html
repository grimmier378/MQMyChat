Renderer

Last Updated: 2026-06-11

ImGui rendering for MQMyChat: main window with native tab bar, pop-out windows, settings window with channel list and events/filters editor, preset manager, theme system, styled widgets.

Entry Point

OnUpdateImGui() (MQMyChat.cpp) calls renderer methods on s_renderer:

  1. RenderMainWindow(*g_chatEngine)
  2. RenderPopOutWindows(*g_chatEngine)
  3. RenderSettingsWindow(*g_chatEngine) if showSettingsWindow
  4. RenderPresetManager(*g_chatEngine) if showPresetManager

Before the render calls, OnUpdateImGui() makes the plugin-owned imanim context current (and creates it on first use with lazy-init disabled); it restores the previous context afterward. The context is destroyed in ShutdownPlugin().

  • Tabs ordered by sortedChannels (sorted by tabOrder then name)
  • First tab: "Main" console (DrawMainConsole)
  • Remaining tabs: one per enabled channel (DrawConsole)
  • Tab reordering detected via DetectTabReorder() (MyChatRenderer.cpp:933)
  • Tab order persisted after TAB_ORDER_SAVE_INTERVAL (3s) debounce via FlushTabOrder() (MyChatRenderer.cpp:954)
  • Right-click context menu: Edit, Pop Out, Delete

Styled & Animated Widgets (imanim)

MQMyChat uses the shared MyUI styled-widget set in Core/Widgets.{h,cpp} (namespace myui), copied verbatim from MQMyUI. These are imanim-driven, theme-colored (ImGuiCol_*) replacements for stock ImGui chrome — pill tabs/lists, animated checkboxes, styled combos, animated collapsing headers, sliders, and a motion toggle.

Where they are used

  • myui::PillTabBar — the Settings window tab bar (RenderSettingsWindow). The main chat tab bar is intentionally still native ImGui::BeginTabBar — DetectTabReorder/FlushTabOrder depend on native drag-reorder, close, and overflow that the pill bar does not replicate.
  • myui::PillSelectable — the settings channel/event lists, and the items inside styled combos (passed an explicit width so the auto-sizing combo popup doesn't collapse them to a sliver).
  • myui::StyledCheckbox — all option/channel/event/filter checkboxes (menus and settings tabs).
  • myui::StyledBeginCombo/StyledEndCombo — the preset selector (Presets menu) and the rename/delete preset combos in the Preset Manager.
  • myui::BeginAnimatedHeader/EndAnimatedHeader — the four Preset Manager sections (Copy / Create / Rename / Delete). Unlike CollapsingHeader, these require a paired End* call.

imanim wiring (MQMyChat.cpp)

  • static iam_context* s_iamCtx — plugin-owned context.
  • OnUpdateImGui(): create once with iam_set_lazy_init(false), iam_context_set_current around the render pass, restore the previous context. Never calls iam_update_begin_frame() (the host drives the shared clock; calling it would double the animation speed).
  • ShutdownPlugin(): iam_context_destroy(s_iamCtx) (mandatory — a dangling context entry crashes the host's next frame).
The earlier hand-rolled AnimateFloat/SpringFloat helpers and the member MyChatRenderer::PillSelectable/PillTabBar (the original workaround for an install/ABI-skew imanim crash) have been removed in favor of this shared set.

Carried but unused

Core/Widgets is synced verbatim from MQMyUI, so it also ships the DirectionRing family (myui::DrawDirectionRing, ResolveColorSource, DirectionRingRadius, PushWindowClip, and the file-scope ColorSource/RingStyle PODs) and the edit-popup owner guard (g_editPopupOwner, which keeps a stale StyledEditField/InputPopup from stealing another field's popup). MQMyChat does not draw the ring (no spawn-bearing UI), but the code compiles in and rides along on each sync.
